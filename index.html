PRIVACY POLICY

This Privacy Policy explains how UNO No Marcy Score Tracker handles information when you use the application.

The application is designed with a local-first approach for its core score-tracking functionality.

1 SECTION 1 — INFORMATION YOU ENTER

The application may allow you to enter information such as:

  • • Player names
  • • Match numbers
  • • Match scores
  • • Player positions
  • • Match dates
  • • Other information required for score tracking

This information is entered by the user for the purpose of using the application's score-tracking features.

2 SECTION 2 — LOCAL STORAGE

For the core score-tracking functionality, the information you enter is stored locally on the device or application storage used by your copy of the application.

The application does not require a user account or registration to use the core score-tracking features.

3 SECTION 3 — NO ACCOUNT REQUIRED

You do not need to create an account or provide personal registration information to use the core score-tracking functionality.

The application is designed to work independently on the user's device.

4 SECTION 4 — NO REMOTE DATABASE FOR CORE SCORE DATA

The core match and score-tracking information is not designed to be stored in a remote database or shared automatically with other users.

Each copy of the application maintains its own locally stored score data.

5 SECTION 5 — DATA ISOLATION

Data stored in one user's copy of the application is separate from data stored in another user's copy.

Sharing the application file or application link does not automatically transfer or share the original user's locally stored match data.

6 SECTION 6 — INTERNET REQUIREMENT

The core score-tracking functionality is designed to work without requiring an internet connection.

Certain future or optional application components may have different technical requirements, but the core local score-tracking system is designed around local storage.

7 SECTION 7 — DATA DELETION

Users can delete their locally stored score information using the application's available data-clearing options.

The Clear Today feature can be used to clear applicable daily information.

The Clear All Data feature is intended to permanently remove the application's saved score and match data from the local storage used by that copy of the application.

Once local data is deleted, it may not be recoverable.

8 SECTION 8 — DEVICE AND STORAGE LIMITATIONS

Because the core score data is stored locally, the availability of that data depends on the device, browser, WebView or application storage environment.

Clearing storage, uninstalling the application, resetting the device, changing storage settings or other system-level actions may remove saved information.

Users should avoid entering highly sensitive or confidential information into the application.

10 SECTION 10 — CHILDREN AND PERSONAL INFORMATION

ABOUT US

UNO No Marcy Score Tracker is a simple, fast and privacy-focused score tracking application designed for UNO No Mercy players, friends and tabletop gaming groups.

The purpose of this app is to make match score tracking easier, faster and more organized. Instead of manually writing scores or maintaining separate notes, players can record their matches directly inside the app and easily review their performance over time.

The app allows users to record matches, enter player points, automatically determine player positions, review daily performance, check weekly and monthly rankings, compare scores and view complete match history.

The application is designed with a local-first approach. Core score-tracking data is stored locally on the user's device rather than being stored in a remote account or shared database.

No account or registration is required for the core score-tracking functionality.
